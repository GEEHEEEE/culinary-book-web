# Кулинарная книга (Веб-версия)

Веб-версия приложения для ведения личной коллекции рецептов и генерации списка покупок. 
Разработана на Python с использованием микрофреймворка Flask.

## 🚀 Как запустить локально
1. Установите зависимости:
   pip install -r requirements.txt
2. Запустите сервер:
   python web_app.py
3. Откройте в браузере http://127.0.0.1:5000

## 🌟 Особенности
* Поиск и фильтрация рецептов по категориям.
* Динамический расчет списка покупок с учетом количества порций.
* Экспорт списка покупок в файл.
* Интеграция с TheMealDB: поиск похожих рецептов в интернете с автоматическим переводом на русский язык.

## 📂 Структура
* web_app.py — маршруты Flask.
* dao.py / db.py — работа с базой данных.
* recipe_api.py — интеграция с внешним API.
* templates/ — HTML-шаблоны.
* init.sql / recipes.db — база данных.
